
# ETH Signal Predictor (Vercel Deployment)

This is a basic frontend + backend project for deploying a crypto signal model using Vercel.

## Folder Structure

- `pages/index.js`: Frontend UI (React)
- `api/run_model.py`: FastAPI backend to run model predictions
- `requirements.txt`: Python dependencies
- `vercel.json`: Vercel build config

## Deployment

1. Push this folder to your GitHub repo.
2. Connect repo to [Vercel](https://vercel.com/).
3. Set root directory to this project folder.
4. Done!
